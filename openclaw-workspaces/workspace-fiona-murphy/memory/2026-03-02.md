## Technical Notes

### Canva API Asset Upload
Working format:
```bash
curl -X POST "https://api.canva.com/rest/v1/asset-uploads" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Length: <file-size>" \
  -H "Content-Type: application/octet-stream" \
  -H 'Asset-Upload-Metadata: {"name_base64":"<base64-filename>"}' \
  --data-binary @file.jpg
```

### Video Export
- Use `"quality": "vertical_1080p"` for reels/stories
- Export takes ~15-20 seconds
