## Critical Cron Fix Discovered (Feb 13)
- **Problem:** `sessionTarget: "main"` + `payload.kind: "systemEvent"` only injects message, doesn't wake agent

- Morning Brief works because it uses isolated/agentTurn and sends email directly (not via main session)
- For Telegram from isolated sessions: must specify target explicitly (chat ID: 8560812913)
