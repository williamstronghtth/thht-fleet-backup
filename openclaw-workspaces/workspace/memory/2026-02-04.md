## RPR Prospecting - What I Learned (archived)
RPR has a powerful built-in prospecting system:
- **Map Search** → Set to Public Record → Apply filters
- **Target Sellers:** Filter by Time Owned (long-time owners), Sold Within, Pre-foreclosure
- **Target Buyers:** Filter by Absentee Owners (finding renters likely to buy)
- **Farm Areas:** Save custom geographic areas for repeated prospecting
- **Export:** Up to 2,000 mailing records/month as CSV or print labels (Avery format)
- **Geographies:** Search by neighborhood, school zone, zip code, or draw custom shapes
- **Mailing:** Can export owner name, property address, or tax billing address
- Key filters: Occupancy Type, Time Owned, Exclude Listed Properties
- This could replace or supplement RedX for finding prospects!
