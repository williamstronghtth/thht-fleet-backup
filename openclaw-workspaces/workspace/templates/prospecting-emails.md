## Tips for Using These
- **Personalize** — Generic emails get deleted. Reference something specific.
- **Short > Long** — Respect their time. Get to the point.
- **One CTA** — Each email asks for ONE thing (call, reply, meeting).
- **Follow up** — If no response in 3-5 days, send a brief follow-up.
- **Track** — Log outreach in CRM so we don't double-contact.
