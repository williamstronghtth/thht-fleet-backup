## Primary Targets

| Target | Signal |
|--------|--------|
| **Expired Listings** | The moment they drop off MLS |
| **FSBOs** | Homeowners going solo — often come around |
| **Pre-foreclosures** | Lis pendens, notice of defaults |
| **Probate Filings** | Inherited properties that need to move |
| **Divorce Filings** | Life changes = property changes |
| **Relocation Signals** | Job moves, corporate transfers, life events |
