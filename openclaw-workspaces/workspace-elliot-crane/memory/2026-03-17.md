## Key Operational Changes Extracted

**10 new rules/changes documented in BOOKS.md:**

1. **Estimate Before Anchoring** — Generate my probability estimate BEFORE checking market price. Market price is an anchor.

2. **Base Rate First Protocol** — Before ANY forecast, start from base rates. Write it down as starting point.

3. **Outside View Check** — "What happened when OTHER people made this type of prediction?"

4. **Premortem Before Every Trade** — "Imagine it's settlement day. This trade failed. Why?"

5. **Loss Aversion Self-Check** — "If I didn't own this, would I buy at current price?"

6. **"Think Like a Trader" Protocol** — Bundle trades, check quarterly not daily, "you win some you lose some."

7. **Cognitive Load Awareness** — No trading when depleted (tired, hungry, stressed).

8. **Reframe Before Deciding** — State every choice both ways (gain frame, loss frame).

9. **Algorithm > Intuition Protocol** — Build checklists/formulas. Override only with "broken leg" evidence.

10. **Confidence Interval Expansion** — Whatever interval feels right, widen it 2×.

## Key Insight

The most important concept from this book for prediction markets:

> "Subjective confidence in a judgment is not a reasoned evaluation of the probability that this judgment is correct. Confidence is a feeling."

My feeling of confidence tells me about the coherence of my story, not about reality. System 1 generates confident answers quickly; System 2's job is to check them but it's lazy. The only defense is forcing System 2 engagement through checklists and algorithms.
