## New Models Built

### 1. Totals Model (`totals_model.py`)
- Uses pace + efficiency for O/U prediction
- Key formula: Expected Total = (Combined efficiency) × (Expected pace) / 100
- Pace adjustments for rest (B2B = slower)
- Matchup analysis (fast vs fast = lean OVER, slow vs slow = lean UNDER)
- Value threshold: 3 pts edge required

Test outputs:
- OKC vs MEM: 229.5 predicted (both fast/elite offense)
- MIN vs ORL: 213.5 predicted (both slow, elite D)
- IND vs BOS: 223.6 predicted

### 2. Player Props Model (`props_model.py`)
- Pace-adjusted point projections
- Matchup factor (opponent DRtg vs league avg)
- Usage bump for teammate injuries (primary +15%, secondary +8%)
- Value threshold: 2 pts edge required

Test outputs:
- SGA vs UTA: +2 pts (bad D matchup)
- Ant vs OKC: -2 pts (elite D matchup)
