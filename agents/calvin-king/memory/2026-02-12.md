## Curriculum - Dean Oliver's Four Factors

Researched and documented the foundational framework:

**The Four Factors (weights):**
1. Shooting (40%) → eFG% = (FG + 0.5×3P) / FGA
2. Turnovers (25%) → TOV% = TOV / (FGA + 0.44×FTA + TOV)
3. Rebounding (20%) → OREB% and DREB%
4. Free Throws (15%) → FT Rate = FT / FGA

**Key insights:**
- The 0.44 coefficient accounts for and-ones, technicals, 3-shot fouls
- Factors are orthogonal — can be modeled independently
- Apply to both offense AND defense (8 factors total)
- Pace adjustment via possessions is critical

## Curriculum - Ed Miller's Market Efficiency

Researched CLV, market efficiency, sharp vs recreational books:

**Closing Line Value (CLV):**
- CLV = Your Line - Closing Line
- Closing line is the "true" line — incorporates all sharp action
- **CLV is more predictive of long-term profit than win rate**
- If you consistently beat CLV, you're profitable

**Market Efficiency:**
- Sports markets are semi-strong efficient
- Sharp books (Pinnacle, Circa) set the lines
- Recreational books (DK, FD, BetMGM) copy with delay
- Lines get MORE efficient as game time approaches

**Sharp vs Recreational Books:**
- Sharp: Accept big bets, move on action, low vig, don't limit winners
- Recreational: Higher vig, copy sharp lines, limit/ban winners, offer promos

**Actionable:**
- Bet early before sharps move the line
- Line shop across all books
- Target inefficient markets (props, alt lines, live betting)
- Track CLV, not just wins
- Use sharp book lines as "truth" benchmark

Saved to: `frameworks/ed-miller-market-efficiency.md`

## Curriculum - Nate Silver's Signal vs Noise

Researched prediction principles, overfitting, sample size discipline:

**Signal vs Noise:**
- Signal = true patterns that persist
- Noise = random variation that won't repeat
- Most prediction failures = mistaking noise for signal

**Overfitting:**
- Model fits past perfectly, predicts future poorly
- Too many variables relative to sample size
- Signs: perfect backtest, drops on new data, extreme predictions
- Fewer variables usually better

**Sample Size Discipline:**
- Variance scales with 1/√n
- NBA 3P% needs ~750 attempts to stabilize
- Team ATS over 10 games = mostly noise
- Use priors + weight by sample size (Bayesian)

**Key Principles:**
- Think probabilistically (distributions, not points)
- Update incrementally (Bayesian)
- Test out-of-sample
- Be a Fox (multiple models, stay humble)
- Track calibration (are 70% bets hitting 70%?)

Saved to: `frameworks/nate-silver-signal-noise.md`

## Curriculum - Tetlock's Calibration & Base Rates

Researched superforecasting, calibration, and base rates:

**Calibration:**
- Your confidence should match your accuracy
- 70% confident → get 70% right
- Most people are overconfident (90% confident, 70% right)
- Track with Brier Score: (prediction - outcome)², lower is better

**Base Rates:**
- Start with unconditional probability before looking at specifics
- Favorite covers ATS: ~50%
- Home team wins: ~58%
- People ignore base rates → the #1 forecasting error

**Superforecaster Traits:**
- Start with outside view (base rate)
- Update incrementally (small moves, not wild swings)
- Use precise probabilities (62%, not "pretty confident")
- Track everything
- Seek disconfirming evidence

**Application:**
1. Establish base rate
2. Adjust for specific factors
3. Convert to bet decision
4. Track calibration over time

Saved to: `frameworks/tetlock-calibration-base-rates.md`

## Model Calculation Engine - BUILT

**Core Engine:** `model/src/model_engine.py`

**Components:**
1. **Base projection** - Net rating differential (team ORtg - DRtg comparisons)
2. **Home court adjustment** - +2.5 pts for home team
3. **Rest adjustment** - B2B penalties, rest advantages
4. **Injury adjustments** - Uses player impact tiers
5. **Probability conversion** - Point edge → win probability (~2.5%/pt)
6. **Confidence assessment** - Based on data quality + edge size

**Sample Run (4 games):**
| Game | Projection | Edge | Confidence |
|------|-----------|------|------------|
| BOS@CLE | CLE -5.8 | +5.8 vs CLE -3.5 | 64.5% |
| OKC@LAL | OKC -10.6 | -0.4 vs OKC -11.0 | 51.0% |
| PHX@DEN | DEN -14.3 | +14.3 vs DEN -5.0 | 85.8% |
| NYK@MIA | MIA +1.3 | -4.3 vs MIA +5.5 | 39.2% |

**"+EV" Picks Identified:**
- DEN -5.0 (85.8% confidence) — Edge flagged as "verify inputs"
- CLE -3.5 (64.5% confidence)

**Safety Features:**
- Edges >10 pts flagged as "verify inputs"
- Adjustment breakdown shows each factor's contribution
- Confidence capped when data sparse

**Output Format:**
```
BOS @ CLE:
  Base: CLE by 3.3 (net rating differential)
  +HCA: +2.5 (Cleveland home)
  +Rest: +0.0 (no advantage)
  +Inj: +0.0 (no tracked scratches)
  Final: CLE -5.8
  Market: CLE -3.5
  Edge: +2.3 pts → 64.5% confidence
```
