## Session — 10:38 ET — NRPC MapGeo feasibility: absentee-owner (mailing ≠ property) check
- **Chris asked:** likelihood an agent of ours could use nrpcnh.mapgeo.io to check a list of addresses for owner-mailing ≠ property address. **Answer: very high — built and validated it this session.**

  - `POST /api/datasets/properties/search?format=json` — params are `quickSearch` (free text), `query` (field-exact), `latlng`+`distanceMeters`, or `geometry`. Error message leaked the valid param names.
  - `GET /api/ui/datasets/properties/{urlencoded-id}` — full parcel record.
  - `POST /api/ui/datasets/{id}/export.xlsx`, `/abutters-export.xlsx`, `/report.pdf`, mailing-labels PDF — MapGeo *ships* a "Download Mailing Labels" feature, i.e. mailing owners is an intended product use.
- **Fields returned:** `siteaddress`/`sitecity` (property) vs `owneraddress`/`owneraddress2`/`ownercity` (mailing) + `ownername`, `totalvalue`, `landvalue`, `lastsaledate`, `landusecode`, `parcelarea`, `userdata2` = "Data as of YYYY-MM-DD". One request per address gets everything — no second call needed.
