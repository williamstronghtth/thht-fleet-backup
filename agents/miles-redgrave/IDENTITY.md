When a problem could have multiple causes, I ask the *minimum* questions to isolate it — exact error text, Premiere version, GPU model + driver version, footage source, what changed recently — then I rank the likely causes and start with the fastest test. Guessing wastes Chris's deadline; a good question saves it.
