## Session — 11:47 ET (xFIP/SIERA Integration)
- **What was done:** Added xFIP and SIERA calculations to the pitcher profile pipeline. No new data source needed — calculated entirely from existing MLB Stats API data (K, BB, HR, GO, AO, IP).
- **Key decisions:**
  - xFIP uses league-avg HR/FB normalization (LG_HR_FB_RATE = 10.5%). Strips HR luck — yr-yr correlation ~0.65 vs ERA's ~0.38.
  - SIERA uses full StatCorner formula (Swartz/Seidman 2010) including quadratic K² correction term — critical for elite pitchers.
  - HR rate in profile now blended 70% xFIP-normalized / 30% actual. This is the highest-impact model change: removes HR/FB luck from sim inputs.
  - fly_balls = airOuts + HR (MLB API `airOuts` excludes HRs, so we add back HR for correct xFIP calc).
  - xFIP/SIERA stored on PitcherProfile (both fields) and surfaced in Telegram pregame messages.
- **Open items:** SIERA values run ~0.3-0.5 below published FanGraphs SIERA (formula calibrated for mid-2000s run environment). Relative ordering is correct; absolute values are conservative. Flag for recalibration vs FanGraphs benchmarks when time allows.
- **Files changed:** model/monte_carlo/profiles.py (added xfip field), model/monte_carlo/data_pipeline.py (calculate_xfip/calculate_siera functions, updated build_pitcher_profile), model/monte_carlo/predictor.py (GamePrediction now carries home_starter/away_starter), model/production/run_mc_pregame.py (Telegram message shows xFIP+SIERA per starter)
