## Workflow Fix: Duplicate Posts Issue

### Problem Identified
When posting to all 4 platforms at once and Instagram fails, my retry attempts were creating duplicate posts on FB/LinkedIn/Twitter.

### Root Cause
Each retry created a brand-new Late post targeting ALL platforms, even when FB/LI/TW had already succeeded.

### Solution Implemented
1. **Platform isolation** - Now posting in 3 separate batches:
   - Batch 1: Facebook + LinkedIn (together)
   - Batch 2: Twitter (short version, always separate)
   - Batch 3: Instagram (isolated - failures don't affect others)

2. **Helper script created:** `scripts/post-social.sh`
   - Includes content hash check before posting
   - Prevents duplicate creation if content already exists

3. **Workflow documented:** `memory/posting-workflow.md`
