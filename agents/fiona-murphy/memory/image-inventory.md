## THE RULES (read before picking an image)

1. **Check "AVAILABLE NOW" below.** If an image is listed there, it's safe to use once.
2. **The instant an image is used (blog OR social, any platform), delete it for good — from
   Google Drive and note it in USED ARCHIVE with the date/post it went to.** Do not just move it
   to an archive folder or leave the file sitting around "in case." One use, then gone. This is
   Chris's explicit instruction (July 23 2026) precisely so a used image can never physically be
   picked up again by mistake.
3. **NEVER use the same image twice in one calendar day, even if it's the only one left.**
   This is a hard rule, not a judgment call. If AVAILABLE NOW is empty and you need an image:
   - Use a text-only post (no image) for social, OR
   - Ask Chris for a new batch before posting.
   Reusing an archived/deleted image is no longer an option at all now that used images are
   deleted outright — there is nothing to fall back to. Flag to Chris instead.
4. **Address-tagged filenames / anything Chris labels "For Just Sold Posts" are RESERVED, not
   available for general use.** If a filename contains a street address (e.g.
   `6-odell-drive-amherst-nh.jpg`, `150-greenville-road-mason-nh-exterior.png`), it belongs to
   that property's Just Sold post ONLY — never general content, never social, never a different
   property. See rule #26 in MEMORY.md.
5. **No stock images, ever.** Unsplash approval revoked July 10, 2026. No Trulia/Zillow/Redfin/CB
   pulls for blog or social featured images. Only images Chris sends directly count as inventory.
6. **When AVAILABLE NOW hits zero, say so plainly and ask Chris for a new batch.** Don't quietly
   patch over it by reusing something.
