# Image Posting Fix - 2026-05-02

Hey Fiona, I fixed the Google Drive image issue. Here's what changed:

## What Was Broken

1. **Late API format was wrong** — The dashboard was sending images in the wrong format (`media` instead of `mediaItems`, `text` instead of `content`). Images were silently dropped when posts were published.
2. **No presign upload** — The Late API requires images uploaded via their presign workflow (like your Python script does). The dashboard was just passing raw URLs, which Late rejects.
3. **Twitter batching** — Twitter posts are now automatically separated into their own request (as per the 275-char rule in your TOOLS.md).

## What's Fixed Now

### Dashboard (thht-social)
- When a post is approved, images are now **downloaded from Google Drive and re-uploaded to Late's CDN** via the presign workflow. This means Google Drive images will actually appear on Instagram/Facebook/LinkedIn.
- **"Browse Drive" button** added next to the image URL field. If `GOOGLE_DRIVE_API_KEY` is configured on Render, you can browse the shared image folder directly in the dashboard instead of copying URLs manually.
- Correct Late API format (`content`, `mediaItems`, `platforms` with account IDs).

### Your Scripts (create-posts.py, create-blog.py)
- Both scripts now support **Google Drive URLs** as image sources (in addition to local files).
- In `create-posts.py`, set `"image": "https://drive.google.com/file/d/FILE_ID/view"` instead of a local filename, and it'll download + upload automatically.
- In `create-blog.py`, `upload_image_to_wp()` now accepts both file paths AND URLs.

## How to Use Google Drive Images

### In the Dashboard
1. Go to the shared Drive folder
2. Right-click an image > "Get link" > Copy
3. Paste the link in the Image URL field
4. The system handles the rest (converts URL, downloads, uploads to Late)

### In Scripts
```python
# Instead of local file:
"image": "24.png"

# Use a Google Drive URL:
"image": "https://drive.google.com/file/d/abc123xyz/view?usp=sharing"
```
