# THHT Agent Fleet — Backup

Snapshot of The Hoover Home Team agent fleet: personas, memory, skills, and system
config. Generated by `scripts/backup-all.sh` (in the ryan-chen workspace).

**Snapshot date:** 2026-09-04

## ⚠️ This repository must stay PRIVATE

It contains agent memory files with internal business context, client references, and
operational notes. Secrets are redacted (see below), but the *content* is still private
company data. Do not make this repository public.

## What's here

| Path | Contents |

| `agents/` | Per-agent workspaces: `SOUL.md`, `IDENTITY.md`, `MEMORY.md`, daily memory, skills, scripts |
| `openclaw-workspaces/` | OpenClaw runtime workspaces, incl. orphaned ones with no git remote |

## Secrets

All credentials are replaced with `<REDACTED:TYPE>` markers. The surrounding field name
is preserved, so each redaction shows *which* credential needs re-supplying — see
`RECOVERY.md` for where to get each one.

Redaction runs two ways: known vendor prefixes (`ghp_`, `sk-`, `xai-`, …) **and** a
field-name catch-all (any `password` / `api_key` / `token` / `secret` assignment). The
catch-all exists because a prefix-only allowlist silently missed three live credentials
in the 2026-09-04 audit — an unknown vendor's key should be redacted by default, not by
luck.

## What is NOT in this backup

- **Media — 241MB, 607 files** (job photos, brand assets, stock photos, video). Excluded
  deliberately: GitHub is a poor host for bulky binaries without LFS, and the free LFS
  tier would be exhausted by a single clone. These files exist **only** in the local
  tarball at `backups/thht-backup-2026-09-04.tar.gz` and still need an off-box home
  (Drive or S3). Derek's job photos in particular are original work and not regenerable.
- **Application code** — already on its own GitHub repos (`thht-crm`, `thht-board`, …).
- `node_modules`, `__pycache__`, virtualenvs, scraped datasets — all regenerable.

## Restoring

See `RECOVERY.md`. Short version: restore workspaces to their paths, re-supply every
`<REDACTED:…>` value, then restart the agent services.
